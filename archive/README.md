# Archive

`logictreenet-oct2026/` is the LogicTreeNet work as of Oct 7, 2026: Colab/Kaggle notebooks (generated by `make_notebooks.py`), executed run notebooks, and the README of that time. Those runs used probabilistic OR-pooling and no channel grouping, which were later found to differ from the paper (Sec. 3.1, 3.4). Their numbers (for example 60.43 hard at scale M) are superseded by `../logictreenet/README.md`. The code they ran is in git history.
